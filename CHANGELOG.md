# Changelog

## 1.0

First full release, following the beta.

- Write RP scripts and send them to chat one line at a time, with the Presenter buttons, keybinds or macros.
- Chat prefixes: Say, Emote, Yell, Party, Raid and Guild.
- Standard emote commands (`/bow`, `/sit`, `/laugh` and so on) on their own line.
- Comment lines starting with `##` for stage directions, shown in the Presenter.
- Multiple scripts, with New, Rename and Delete.
- Resizable Editor and Presenter windows, remembered between sessions.
- Warning for lines over 250 characters.
- In-game help window (the **?** button) and tooltips on the editor buttons and the Presenter's Restart, script and close buttons.
- The Presenter's Reset button is now called **Restart**, and `/tn reset` still works.
- Keybinds for Send, Skip, Back, Restart and Toggle Presenter.
